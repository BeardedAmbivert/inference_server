Embedding Inference Server

FastAPI MiniLM embeddings with async dynamic batching. This page is the Space landing; the interactive API explorer is Swagger.

checking health Open Swagger ReDoc /health /metrics

Endpoints

MethodPathWhat it does
GET / This landing page
GET /health Readiness probe. 200 when the model and batch worker are up, else 503.
GET /metrics Same snapshot as /health, always 200.
POST /embed Embed a JSON list of texts. Returns 384-d vectors.
GET /docs Swagger UI generated from the FastAPI OpenAPI schema.
GET /redoc ReDoc view of the same schema.
GET /openapi.json Raw OpenAPI document.

Try POST /embed

curl

curl -X POST /embed \
  -H "Content-Type: application/json" \
  -d '{"texts": ["hello world"]}'
